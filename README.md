# Mercy — Charity Donation Website

Multilingual website for a charity/donation initiative, built with Next.js.

## Features

- Internationalization (react-intl, react-i18next) — multi-language support
- Online donations via PayPal (react-paypal-button-v2)
- Responsive image gallery with masonry layout (react-responsive-masonry, macy)
- Animated counters for donation/impact statistics (react-countup)
- UI built with Bootstrap and React Bootstrap

## Tech stack

- Next.js
- React
- Bootstrap / React Bootstrap
- SCSS

## Getting started

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
